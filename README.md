# 청소년기 가정 내 도서 보유 수와 성인기 문해력 분석 코드

이 저장소는 다음 논문의 분석 재현을 위한 R 코드를 제공한다.

**청소년기 가정 내 도서 보유 수가 성인기 문해력에 미치는 영향: PIAAC 2주기 한국 자료를 활용한 인과효과 추정과 민감도 분석**

## 1. 저장소 구성

- `README.md`: 자료 및 실행 안내
- `LICENSE`: 코드 라이선스
- `.gitignore`: 원자료 및 임시 파일 제외 설정
- `book-ownership-and-adult-skills.R`: 분석 코드

## 2. 분석 자료

본 연구는 OECD 국제성인역량조사(PIAAC) 2주기 한국 Public Use File을 사용하였다. 원자료는 이 저장소에 포함하지 않는다.

[OECD PIAAC 2주기 데이터베이스](https://www.oecd.org/en/data/datasets/PIAAC-2nd-Cycle-Database.html)에서 한국 자료를 내려받아 저장소 최상위 폴더에 `prgkorp2.csv`라는 이름으로 둔다. 파일명이 다르면 이름을 변경하거나 코드의 `DATA_PATH`를 수정한다. 대소문자를 구분하는 파일 시스템에서는 파일명 대소문자도 일치해야 한다.

## 3. 분석 코드 및 출력

| 코드 출력 | 내용 | 저장 파일 |
| --- | --- | --- |
| `표1_기술통계_교차분석` | 도서 보유 수 범주별 배경변수의 가중 분포 및 교차분석 | `table1.csv` |
| `표2_회귀분석` | 도서 보유 수와 성인기 문해력의 복합표본 다중회귀분석 | `table2.csv` |
| `표3_민감도분석` | 미관측 교란요인에 대한 민감도 분석 | `table3.csv` |
| `기준공변량_부분설명력` | 비교기준 공변량의 관찰된 부분설명력 | `benchmark_r2.csv` |

교차분석은 `survey::svychisq()`의 `F` 검정을 우선 사용하며, 계산되지 않으면 `adjWald`, `Chisq` 순서로 시도한다.

## 4. 실행 환경 및 패키지

R 또는 RStudio에서 실행하며, 다음 패키지를 사용한다.

- `tidyverse`
- `survey`
- `sensemakr`

설치되지 않은 패키지는 코드 실행 시 자동으로 설치된다. 코드의 인코딩은 UTF-8이다. RStudio에서 한글이 깨지면 `File > Reopen with Encoding`에서 UTF-8을 선택한다.

## 5. 실행 방법

원자료와 분석 코드를 같은 폴더에 두고, R의 작업 디렉터리를 해당 폴더로 설정한 뒤 실행한다.

```r
source("book-ownership-and-adult-skills.R", encoding = "UTF-8")
```

콘솔에 분석 결과와 자료 점검 정보가 출력된다. 표의 설명 주석은 출력하지 않는다. 민감도 분석은 10개 plausible value와 80개 반복가중치별로 모형을 재추정하므로 시간이 소요될 수 있다.

코드 상단에서 출력 옵션을 설정한다.

```r
DATA_PATH   <- "prgkorp2.csv"
USE_VIEWER  <- interactive()
SAVE_OUTPUT <- FALSE
OUTPUT_DIR  <- "output"
```

`USE_VIEWER`가 `TRUE`이면 `View()`로 표를 연다. `SAVE_OUTPUT`을 `TRUE`로 설정하면 `output` 폴더에 `table1.csv`, `table2.csv`, `table3.csv`, `benchmark_r2.csv`가 저장된다.

## 6. 분석 설정

1. 결과변수는 문해력 plausible values인 `PVLIT1`부터 `PVLIT10`까지이다.
2. 최종가중치 `SPFWT0`과 반복가중치 `SPFWT1`부터 `SPFWT80`까지를 적용한다.
3. 코드의 복합표본 설계는 Fay BRR, 조정계수 0.3으로 설정되어 있다.
4. PV별 추정치와 분산은 Rubin의 결합규칙으로 통합한다.
5. 분석 변수와 가중치에 결측이 없는 완전사례를 사용한다. 결측 제외 인원과 최종 분석 표본 수는 실행 시 출력된다.
6. 도서 보유 수의 인과적 총효과 추정을 목적으로 최종학력·직업상태·직업 관련 훈련 참여 등 14세 이후의 변수는 통제하지 않는다.

## 8. 민감도 분석

기준집단인 `10권 이하`와 비교되는 모든 도서 보유 수 범주를 분석한다. 비교기준은 부모 교육수준의 `대졸 이상` 더미이다.

`sensemakr`의 부분설명력 경계를 이용하여 비교기준 대비 1배, 2배, 3배 시나리오의 조정 추정치를 계산한다. 각 PV에서 최종가중치와 반복가중치를 적용한 가중 회귀를 적합하고, 비교기준의 부분설명력과 조정 추정치를 다시 계산한다. 반복추정치로 분산을 구한 뒤 PV별 결과를 Rubin의 결합규칙으로 통합한다.

표 3에는 다음 결과를 제시한다.

- **동일 부분R2 CI 임계값**: 원인변수와 결과변수에 대한 교란요인의 부분설명력이 같은 조건에서, 결합 신뢰구간이 처음 0에 닿는 교란 강도.
- **rY=1일 때 rD CI 임계값**: 결과변수에 대한 부분설명력을 1로 고정했을 때, 같은 조건에 필요한 원인변수에 대한 부분설명력.
- **1배·2배·3배 조정치(SE)**: 각 시나리오의 조정 추정치와 반복추정 표준오차.

신뢰수준은 기본 95%이며 `SENSE_ALPHA`로 설정한다. 두 CI 임계값은 이 코드에서 정의한 지표로, `sensemakr`의 기존 RV 및 극단적 RV와 구분된다. 표준오차는 민감도 조정 통계량의 반복추정 표준오차이다.
