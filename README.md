# 청소년기 가정 내 도서 보유 수와 성인기 문해력 분석 코드

이 저장소는 다음 논문의 분석 재현을 위한 R 코드를 제공한다.

**청소년기 가정 내 도서 보유 수가 성인기 문해력에 미치는 영향: PIAAC 2주기 한국 자료를 활용한 분석**

.

## 2. 분석 자료

본 연구는 OECD 국제성인역량조사(PIAAC) 2주기 한국 Public Use File을 사용하였다.

원자료는 저작권 및 배포 조건을 고려하여 이 저장소에 포함하지 않는다. 분석을 재현하려면 OECD PIAAC 2주기 데이터베이스에서 한국 자료를 내려받은 뒤, 파일명을 다음과 같이 지정하여 이 저장소의 최상위 폴더에 두어야 한다.

```text
prgkorp2.csv
```

PIAAC 2주기 데이터베이스 주소는 다음과 같다.

```text
https://www.oecd.org/en/data/datasets/PIAAC-2nd-Cycle-Database.html
```

내려받은 파일명이 대문자(`PRGKORP2.csv`)인 경우, macOS 및 Linux에서는 파일명 대소문자를 구분하므로 소문자로 변경하거나 코드의 `DATA_PATH` 값을 수정해야 한다.

## 3. 분석 코드

주요 분석 코드는 다음 파일에 있다.

book-ownership-and-adult-skills.R

이 코드는 다음 분석을 수행하며, 각 결과는 논문의 표와 다음과 같이 대응한다.

| `표2_회귀분석` | 표 2 | 14세 시점 도서 보유 수와 성인기 문해력의 복합표본 다중회귀분석 |
| `표3_민감도분석` | 표 3 | 미관측 교란요인에 대한 민감도 분석 |

## 5. 실행 방법

`prgkorp2.csv`와 `book-ownership-and-adult-skills.R`을 같은 폴더에 둔 뒤, R 또는 RStudio에서 다음 명령어를 실행한다.

```r
source("book-ownership-and-adult-skills.R")
```

분석이 끝나면 콘솔에 표 1부터 표 3까지의 결과와 각 표의 주가 출력된다. 10개 plausible value와 80개 반복가중치를 사용하므로 실행에는 다소 시간이 소요된다.

코드 상단의 실행 옵션으로 출력 방식을 조정할 수 있다.

```r
DATA_PATH   <- "prgkorp2.csv"   # 원자료 경로
USE_VIEWER  <- interactive()    # RStudio 표 창 자동 실행 여부
SAVE_OUTPUT <- FALSE            # TRUE이면 표를 CSV로 저장
OUTPUT_DIR  <- "output"         # 저장 폴더
```

`SAVE_OUTPUT`을 `TRUE`로 지정하면 `output/table1.csv`부터 `output/table3.csv`까지 저장된다.

## 6. 분석 원칙

1. 결과변수는 문해력 plausible values인 `PVLIT1`부터 `PVLIT10`까지를 사용하였다.
2. 최종가중치 `SPFWT0`과 80개 반복가중치 `SPFWT1`부터 `SPFWT80`까지를 반영하였다.
3. 반복가중치에 기초한 분산 추정에는 Fay의 균형반복복제법(BRR)을 적용하였으며, Fay 조정계수는 0.3으로 설정하였다.
4. 각 plausible value별 분석 결과는 Rubin의 결합규칙에 따라 통합하였다.
5. 분석에는 결과변수, 원인변수, 통제변수, 최종가중치 및 반복가중치에 결측이 없는 완전사례만 포함하였다. 원자료 6,198명 중 312명(5.03%)을 제외한 5,886명이 최종 분석 표본이다.
6. 도서 보유 수의 인과적 총효과를 추정하기 위해, 14세 시점 이후에 형성되는 최종학력·직업상태·직업 관련 훈련 참여 등은 통제변수에 포함하지 않았다.

## 8. 민감도 분석

민감도 분석은 Cinelli와 Hazlett(2020)의 접근을 바탕으로 수행하였으며, 기준집단인 `10권 이하`와 비교되는 모든 도서 보유 수 범주의 추정효과에 적용하였다.

각 범주에 대해 강건성 값(RV)과 극단적 RV를 산출하고, 기준 공변량으로 `부모 교육수준: 대졸 이상`을 설정하여 가상의 미관측 교란요인이 이 공변량의 1배, 2배, 3배 수준의 부분설명력을 갖는 경우의 조정 추정치와 조정 표준오차를 함께 제시하였다.

`sensemakr` 패키지는 `lm` 객체를 요구하므로, 기준 공변량의 부분설명력은 최종가중치를 적용한 `lm` 모형에서 산출하고, 조정 추정치와 조정 표준오차는 복합표본 설계를 반영한 추정치와 설계 자유도를 기준으로 계산한 뒤 Rubin의 결합규칙으로 통합하였다.
